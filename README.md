# Karkia Tarabar Asia — Static Landing

لندینگ استاتیک کارکیا ترابر آسیا برای آپلود مستقیم روی هاست.

Static HTML landing page for Karkia Tarabar Asia.

**Site:** https://www.karkiatarabar.com/

## Upload to host / آپلود روی هاست

Upload these files into `public_html` (or the domain document root):

این فایل‌ها را داخل `public_html` آپلود کنید:

- `index.html`
- `assets/`
- `robots.txt`
- `sitemap.xml`
- `.htaccess`

Do not upload WordPress files from this branch. The WordPress host package lives on the `wordpress` branch.

وردپرس را از این شاخه آپلود نکنید. بسته وردپرس روی شاخه `wordpress` است.

## Layout

```text
index.html
.htaccess
robots.txt
sitemap.xml
assets/
  fonts/
  images/qr/
  vendor/fontawesome/
  vendor/*.js
  logo.png, favicon*.png, hero.jpg, hero.mp4
```
